
# Disk Scheduling Simulator

An interactive Operating Systems project built with Python and Streamlit to simulate and compare four disk scheduling algorithms.

## Algorithms Implemented

- FCFS (First Come, First Served)
- SSTF (Shortest Seek Time First)
- SCAN
- C-SCAN (Circular SCAN)

## Features

- Interactive disk configuration
- Custom disk request input
- Comparison of total head movement
- Performance dashboard
- Head movement charts
- Step-by-step movement details
- CSV export of simulation results

## Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib

## Installation

1. Clone or download this repository.
2. Install the required packages:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py

4. Open the local URL displayed in the terminal.

## Project Purpose

This project demonstrates how disk scheduling algorithms manage disk-head movement and how their performance varies with the request sequence and initial direction.
